# Planning a small workshop

Begin by writing one learning goal. That goal determines which activities belong in the workshop.

Arrange activities so that a demonstration comes before independent practice. In the example workshop, the facilitator demonstrates a folding method and then participants try it themselves.

Set a time limit for each activity to protect time for the final review. The example plan gives the demonstration five minutes and practice ten minutes.

Prepare the materials before participants arrive. In the example, each seat receives two sheets of paper.

Finish with a question tied to the learning goal to check understanding. The facilitator asks participants to describe the folding method without looking at the demonstration.

Revise the next workshop using the participants' feedback. In the example, participants request more practice time, so the next plan extends practice.
