### 1. Define the learning goal
**Key concept:** One learning goal determines which activities belong in the workshop.
**Explanation:** Write the goal before choosing the workshop's activities.
**Self-test:** What should determine which activities belong? Answer: The learning goal.

### 2. Demonstrate before practice
**Key concept:** Arrange a demonstration before independent practice.
**Explanation:** Participants first see the method and then try it themselves.
**Example:** The facilitator demonstrates a folding method before participants practice it.

### 3. Protect review time
**Key concept:** Time limits for activities protect time for the final review.
**Explanation:** Give each activity a time limit in the workshop plan.
**Example:** The example plan allows five minutes for demonstration and ten minutes for practice.

### 4. Prepare materials in advance
**Key concept:** Prepare the materials before participants arrive.
**Explanation:** Put the workshop materials in place ahead of arrival.
**Example:** Each seat receives two sheets of paper.

### 5. Check the learning goal
**Key concept:** A closing question tied to the learning goal checks understanding.
**Explanation:** End the workshop with a question about what participants were meant to learn.
**Example:** Participants describe the folding method without looking at the demonstration.

### 6. Revise using feedback
**Key concept:** Use participants' feedback to revise the next workshop.
**Explanation:** Feedback informs changes to the next plan.
**Example:** Participants request more practice time, so the next workshop extends practice.
